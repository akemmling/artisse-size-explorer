Dynamic size explorer for the Artisse™ Intrasaccular Device

This Artisse size explorer turns the static Medtronic sizing chart into a dynamic one. A static table can only print a handful of fixed compression/height pairs; it cannot list every Artisse compression/height combination — this dynamic table can (see background info). Critique and feedback welcome.

Video walkthrough — how to use this explorer “Artisse sizing for brain aneurysm using the dynamic height explorer” on YouTube

Move the slider to see how height changes with compression for each Artisse. Enter a measured aneurysm and let the tool flag up to three devices (★) where compressed shape probably fits (or choose your desired protrusion at the neck).
